# Student Placement Analysis

A Python script that summarizes student placement data, analyzes placement and
salary trends, and exports a cleaned CSV.

## Requirements

- Python 3.9 or newer
- The CSV dataset named
  `Student_Placement_Analyst_Project FE Added and cleaned file.csv`

The dataset is not included in this repository. Keep it private and place your
authorized local copy in the same folder as `project 1.py`.

## Run

```powershell
python -m pip install -r requirements.txt
python "project 1.py"
```

The script writes `student_placement_final_analysis.csv` to the project folder.
This output and CSV datasets are excluded from Git by `.gitignore`.
